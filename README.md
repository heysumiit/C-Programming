## Compile and Run

Make sure a C compiler such as GCC is installed and available in your system's PATH.

### Compile

```bash
gcc filename.c -o program
```

### Run on Windows

```bash
program.exe
```

### Run on Linux or macOS

```bash
./program
```

Replace `filename.c` with the name of your C source file.
